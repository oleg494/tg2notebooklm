tg/ 2notebooklm client-side / no upload

Telegram Desktop → NotebookLM

Чат остаётся у вас.
В NotebookLM попадает структура.

JSON или HTML, сообщения, связи, фото, документы и аудит каждого решения. Конвертация выполняется в браузере; сервер не получает экспорт.

  1. 01Выберите экспортresult.json или messages*.html с папкой files
  2. 02Соберите пакетMarkdown, PDF-атласы, CSV и нативные файлы
  3. 03Загрузите sourcesровно в пределах вашего лимита источников
Локальная обработка. Python запускается в Web Worker через Pyodide. Содержимое файлов не уходит на наш сервер.
