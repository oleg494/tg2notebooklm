# tg2notebooklm

**[→ Открыть веб-версию (без установки)](https://oleg494.github.io/tg2notebooklm/)** · [Documentation in English](README.md)

Превращает экспорты чатов Telegram Desktop в компактный, детерминированный набор
источников для [Gemini Notebook](https://notebooklm.google.com/) (бывший NotebookLM) — локально, без загрузок в сеть и со строгим бюджетом источников.

Собственный экспорт Telegram даёт либо `result.json` на 28 МБ, либо сотню
HTML-файлов с пагинацией. Gemini Notebook плохо принимает и то, и другое: лимит
источников на блокнот (50/100/300/500/600 в зависимости от тарифа), потолок
500 000 слов и 200 МБ на источник, и никакой возможности массово импортировать
тысячи фотографий из чата. Инструмент переупаковывает **оба** формата экспорта
в папку, которую можно перетащить в блокнот одним движением.

## Что делает

- **Автоопределение** обоих форматов экспорта Telegram Desktop: машиночитаемый JSON
  (`result.json`, отдельный чат или весь аккаунт) и HTML с пагинацией
  (`messages.html`, `messages2.html`, …).
- **Сохраняет структуру**: ID сообщений Telegram, время, авторов, ответы
  (включая кросс-чатовые и «висячие» цели), пересылки с исходным отправителем и датой,
  правки, реакции с количеством и последними отреагировавшими, опросы, служебные
  события, темы форума, кнопки ботов и rich-text-разметку (жирный/курсив/код/pre/
  цитата/спойлеры/ссылки).
- **Упаковывает текст чата** в хронологические Markdown-источники, разбиваемые только
  по границам сообщений, под вашим лимитом слов и никогда не выше 500k слов.
- **Упаковывает изображения** в PDF-атласы с подписями (много фото на один слот
  источника, у каждого — имя чата, ID сообщения, дата, автор и текст подписи
  для цитирования и поиска).
- **Тратит оставшиеся слоты** на нативные источники: сначала документы
  (PDF/DOCX/PPTX/EPUB), затем крупные тексты, затем аудио/видео (Gemini Notebook
  транскрибирует аудио при импорте).
- **Встраивает мелкие текстовые вложения** (код, конфиги, CSV, заметки, HTML) прямо
  в позицию сообщения — они анализируемы, не расходуя слот источника.
- **Фиксирует каждое решение**: `manifest.json` + `report.md` + `01_attachments.csv`
  внутри пакета объясняют каждое вложение — включено, встроено, упаковано в атлас,
  недоступно (заглушки Telegram «File not included») или исключено из-за
  исчерпания бюджета. Ничего не пропадает молча.
- **Детерминированность**: одинаковый вход и флаги дают побайтово идентичный вывод —
  можно перезапускать, сравнивать и точечно заменять обновлённые источники.
- **Локально и приватно**: никаких сетевых запросов; OCR и транскрибация аудио —
  опциональные локальные модули.
- **Работает в браузере**: статическая версия на GitHub Pages (Python через Pyodide
  в Web Worker) конвертирует те же экспорты без загрузки на сервер — см.
  [Браузерная версия](#браузерная-версия-github-pages).

## Установка

```bash
pip install tg2notebooklm        # или: uv tool install tg2notebooklm
```

Или из исходников (Python 3.11+):

```bash
git clone https://github.com/oleg494/tg2notebooklm
cd tg2notebooklm
uv sync
```

## Быстрый старт

1. В Telegram Desktop: чат → ⋮ → *Экспорт истории чата* → выберите
   **Machine-readable JSON** (с фото/файлами) или **HTML**.
2. Посмотрите, что у вас есть (контент не печатается):

   ```bash
   tg2notebooklm inspect path/to/ChatExport_2026-09-01 --plan standard
   ```

3. Конвертируйте:

   ```bash
   tg2notebooklm convert path/to/ChatExport_2026-09-01 \
     --output my-notebook-package \
     --plan standard
   ```

4. Откройте [notebooklm.google.com](https://notebooklm.google.com/), создайте блокнот
   и загрузите **все файлы из `my-notebook-package/sources/`**.
   `manifest.json` и `report.md` оставьте локально (это не слоты источников).

### Любая папка с файлами (Telegram не нужен)

Укажите `convert` на обычную папку — документы, заметки, код, медиа — и она станет
тем же пакетом с бюджетом источников: мелкие текстовые файлы встраиваются в
Markdown-чанки, изображения идут в PDF-атласы, «родные» PDF склеиваются, остальное
копируется нативно:

```bash
tg2notebooklm convert path/to/my-folder --plan standard
```

Определение автоматическое: папки с `result.json`/`messages.html` парсятся как
экспорты Telegram; любая другая непустая папка становится дампом файлов.

### Тарифы и бюджеты

| Флаг | Источников на блокнот |
|---|---|
| `--plan standard` (по умолчанию) | 50 |
| `--plan plus` | 100 |
| `--plan pro` | 300 |
| `--plan ultra20` / `--plan ultra30` | 500 / 600 |

Переопределяется через `--source-limit N` под любой бюджет. Конвертер резервирует
один слот под индекс и один под каталог вложений, затем вписывает Markdown чата,
атласы изображений и нативные файлы в остаток — никогда не превышая лимит.
Официальные лимиты: [справка Google](https://support.google.com/gemininotebook/answer/16213268).

## Браузерная версия (GitHub Pages)

Тот же конвертер работает полностью локально в браузере как статическая страница:
Python исполняется в Web Worker через [Pyodide](https://pyodide.org/) (загружается
с CDN при первом использовании, затем кэшируется браузером), а папка экспорта
монтируется только для чтения (WORKERFS) — ничего никуда не отправляется.
Результат — детерминированный ZIP с той же структурой, что у CLI:
`sources/` + `manifest.json` + `report.md`.

Предпочитайте CLI, когда:

- экспорт весит много гигабайт — вкладка браузера держит в памяти куда меньше,
  чем скрипт;
- нужны опциональные локальные модули: OCR (Tesseract) или транскрибация Whisper;
- нужна автоматизация (скрипты, CI, пакетные запуски).

**Свой деплой:** при пуше в `main` workflow `.github/workflows/pages.yml` собирает
wheel и статический сайт (`_site/`) и публикует его через GitHub Pages Actions.
Включается один раз в настройках репозитория: *Settings* → *Pages* → *Source:
GitHub Actions*.

## На что тратится бюджет источников

1. `00_index.md` — индекс пакета, обзор чатов, подсказки для запросов.
2. `chat_*.md` — хронологический корпус сообщений (со встроенными мелкими
   текстовыми вложениями).
3. `01_attachments.csv` — все решения по вложениям, доступен как источник-таблица.
4. `images_*.pdf` — атласы изображений (по умолчанию 160 фото на PDF, 8 на страницу).
5. `native_*` — скопированные оригиналы: сначала документы, затем крупные тексты,
   затем аудио/видео по размеру.

Что не влезло — попадает в манифест с причиной (`excluded_source_budget`,
`unavailable`, `metadata_only`, …).

## Опциональное локальное обогащение

```bash
# Распознавание речи для войсов/аудио (нужно: pip install tg2notebooklm[transcribe])
tg2notebooklm convert EXPORT --output OUT --plan pro --transcribe-audio --whisper-model small

# OCR для фото (нужен исполняемый файл tesseract в PATH)
tg2notebooklm convert EXPORT --output OUT --plan pro --ocr-images --ocr-languages eng+rus

# Ограничить обогащение на огромных экспортах
--enrichment-max-files 50
```

Транскрипты встают встроенными в позицию исходного сообщения.

## Приватность

- Конвертер **не делает сетевых запросов** (модели whisper загружаются локально).
- Пути экспорта считаются недоверенными: traversal и абсолютные пути отклоняются.
- Сгенерированные источники содержат реальный контент чата и имена участников —
  проверяйте перед загрузкой или публикацией.

## Ограничения

- Медиа, которые Telegram сам не выгрузил (заглушки вида «File not included.
  Change data exporting settings to download.»), восстановить нельзя; конвертер
  записывает их как `unavailable` с сохранением метаданных.
- Стикеры/анимации/видео, отсутствующие в экспорте, остаются только в метаданных.
- У потребительского Gemini Notebook нет официального API загрузки; автоматизация
  вне области проекта (Enterprise-пользователи могут прогнать ту же папку `sources/`
  через официальный API).
